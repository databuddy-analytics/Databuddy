# Dashboard App

This is the main Databuddy dashboard built with [Next.js](https://nextjs.org).

## Getting Started

From the repository root, run the dashboard in development mode:

```bash
bun run dev:dashboard
```

Then open [http://localhost:3000](http://localhost:3000).

## Useful Commands

Run these from the repository root:

- `bun run dev` - start all apps in development mode
- `bun run dev:dashboard` - start only the dashboard app
- `bun run build` - build all workspace packages and apps
- `bun run lint` - run linting across the monorepo

## Where to Edit

- `app/` - route handlers and pages
- `components/` - shared UI components for the dashboard
- `lib/` - app-level utilities and integrations

For project-wide setup and contribution steps, see the root [README](../../README.md) and [CONTRIBUTING.md](../../CONTRIBUTING.md).
