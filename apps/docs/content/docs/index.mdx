Databuddy is a lightweight analytics platform for developers. One asynchronous browser tracker collects analytics, errors, and web vitals; the same platform adds feature flags, short links, and AI analysis.

<Callout type="info">
  <strong>TL;DR</strong> — a lightweight tracker, connected product analytics,
  and a dashboard designed for developers.
</Callout>

## Analytics Features

**Essential Tracking**

- Page views with automatic SPA routing
- Anonymous user sessions
- Traffic sources and referrers
- Real-time visitor monitoring

**Performance Monitoring**

- Core Web Vitals (LCP, INP, CLS)
- Page load timing metrics
- Error tracking (Hobby plan and up)
- Custom business events

**Conversion & Revenue**

- Custom events for checkout and product flows
- Revenue analytics via payment webhooks (alpha)
- Funnels and goals for conversion analysis
- Feature flags with targeting rules

**Monitoring**

- Uptime monitoring with alerts
- Public branded status pages

## Key Benefits

**Collection Controls**
Cookieless tracking, optional user profiles, path masking, and opt-out support. Review your configuration and consent requirements before deployment.

**Developer‑Friendly**
TypeScript, React components, comprehensive API with interactive playground, and detailed docs.

**Cross‑Platform**
Browser and server SDKs for web applications and integrations.
