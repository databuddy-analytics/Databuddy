# Acknowledgments

We would like to thank the following projects, organizations, and individuals who have contributed to making Databuddy possible:

## Open Source Projects

Databuddy is built on the shoulders of giants. We are grateful to the maintainers and contributors of these excellent open source projects:

### Core Framework & Runtime
- [Next.js](https://nextjs.org/) - The React framework for production
- [React](https://reactjs.org/) - A JavaScript library for building user interfaces
- [Bun](https://bun.sh/) - Fast all-in-one JavaScript runtime
- [TypeScript](https://www.typescriptlang.org/) - JavaScript with syntax for types
- [Turborepo](https://turbo.build/repo) - High-performance build system for JavaScript and TypeScript monorepos

### Database & Data Management
- [PostgreSQL](https://www.postgresql.org/) - The world's most advanced open source database
- [ClickHouse](https://clickhouse.com/) - Fast open-source column-oriented database management system
- [Drizzle ORM](https://orm.drizzle.team/) - TypeScript ORM for SQL databases
- [Redis](https://redis.io/) - In-memory data structure store

### UI & Styling
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework
- [Radix UI](https://www.radix-ui.com/) - Unstyled, accessible components for building design systems
- [Phosphor Icons](https://phosphoricons.com/) - Flexible icon family for interfaces

### API & Type Safety
- [ORPC](https://orpc.dev/) - Type-safe RPC framework
- [Elysia](https://elysiajs.com/) - Fast and friendly Bun web framework
- [Zod](https://zod.dev/) - TypeScript-first schema validation

### Development Tools
- [Fumadocs](https://fumadocs.vercel.app/) - Documentation framework
- [Ultracite](https://github.com/stackblitz/ultracite) - Advanced linting and formatting
- [Prettier](https://prettier.io/) - Opinionated code formatter
- [Tanstack Query](https://tanstack.com/query) - Powerful asynchronous state management

### Utilities
- [Day.js](https://day.js.org/) - Fast 2kB alternative to Moment.js
- [nanoid](https://github.com/ai/nanoid) - A tiny, secure, URL-friendly unique string ID generator

## Hosting & Infrastructure

- [Vercel](https://vercel.com/) - Special thanks to Vercel for supporting Databuddy through their [OSS Program](https://vercel.com/oss)

## Community

## Inspiration

Databuddy draws inspiration from privacy-focused analytics platforms and the broader open source analytics community:

- [Plausible Analytics](https://plausible.io/) - For pioneering privacy-first web analytics
- [Umami](https://umami.is/) - For showing what's possible with open source analytics
- [PostHog](https://posthog.com/) - For their comprehensive approach to product analytics
